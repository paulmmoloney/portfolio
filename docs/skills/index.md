## Documentation Tools

### Madcap Flare

:simple-homepage: [https://www.madcapsoftware.com](https://www.madcapsoftware.com)

One of the field's most popular proprietary documentation systems. Flare enables topic-based authoring in HTML and single sourcing content to multiple publication streams (web, mobile, PDF).

In my career, I used this in Valista, BAE Systems Applied Intelligence, and Fenergo.

- **BAE Systems Applied Intelligence:** At BAE Systems, I led migration from Word to MadCap Flare, implementing single-sourcing to streamline PDF and online help generation, which significantly reduced production time and errors.

- **Fenergo:** I was technical lead in migrating their documentation from an internal-only intranet of Microsoft Word documents to a fully searchable document portal (unfortunately no longer available), accessible both inhouse and to clients. This involved converting all documentation to Madcap Flare native files.

    That worked well, and the conversion from Word to Flare brought many benefits, but also meant that involving people outside the documentation team in either the review process or the contribution process would have involved either buying multiple additional copies of Madcap Flare or Contributor.

    I researched and found a third-party tool Markdown Plugin being produced by a one-man company named :lucide-external-link: [ImprovementSoft](https://www.improvementsoft.com). At the time it cost the equivalent of a few euros a month. With that we were able to convert our documentation from native Flare files to Markdown and implement a Docs-as-Code process. The Markdown files now sat along the code, ensuring reviews were more tightly coupled with code changes and could be reviewed and edited with the same tools.
