[www.r3.com](http://www.r3.com)

R3 is a leading provider of digital currency, digital assets, and
interoperability solutions using blockchain technology.

As Senior Technical Writer, I:

  GitHub, and published via automated pipelines using Hugo. The

  make full use of our Corda DLT platform.

- Authored user guides, reference manuals, training manuals, and API

  assets solutions.

  Confluence content into print-ready PDFs using partially automated

  replaced an existing commercial solution costing thousands per annum.

- Provided other departments with documentation governance: for example,
  produced Word templates, and reviewed and edited material.

## Fenergo \| Technical Writer May 2018 to Jul 2022

[www.fenergo.com](https://www.fenergo.com)

Fenergo is an Irish "unicorn" company valued at €1bn that consistently
ranks as the number one provider of Client Lifecycle Management and Know
Your Customer (KYC) solutions.

As a Technical Writer, I:

- Migrated their documentation from an intranet of Microsoft Word
  documents to a fully searchable document portal using Docs as Code
  methodology. This involved converting all documentation to Markdown,
  storing it in Azure alongside the codebase, automating its conversion
  to MadCap Flare files using a third-party plugin, and publishing to a
  MadCap Central documentation portal. The new documentation portal
  enabled internal and external developers to find up-to-date
  information more quickly.

- Authored Fenergo's FenE documentation portal, which included product
  guides, API guides, and release notes, working in an Agile
  environment.
