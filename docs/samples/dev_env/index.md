# Internal Developer Guide

When I started in Fenergo, I needed to set up a developer environment on my own machine and found there was no simple guide for this. Several developers had all started their own guides, but these had never been maintained. Additionally, they had deviated over time in their recommendations.

With that in mind I set to create one for myself. Originally this was published in [MadCap Flare](../../skills/index.md#madcap-flare).
